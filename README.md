# AliPaySite

Промо-сайт AliPay — студии кастомизации готовых вещей.

## Что делает сайт

AliPay не производит и не шьёт одежду. Сайт показывает две модели заказа:

1. **Наша футболка или шоппер** — AliPay предоставляет готовую основу и наносит согласованный рисунок.
2. **Любая подходящая вещь клиента** — клиент передаёт свою вещь, а AliPay наносит на неё согласованный дизайн.

Заказ оформляется через Telegram: [@VespidKitten875](https://t.me/VespidKitten875). Онлайн-оплата в frontend не имитируется.

## Технологии

- React 18
- Vite 8
- GitHub Pages
- GitHub Actions
- CSS без UI-фреймворка
- локальные фотографии из `public/photos`

## Структура

- `src/App.jsx` — разметка страницы, модальные окна, scroll-reveal и интерактив.
- `src/styles.css` — визуальная система, glassmorphism, responsive и motion.
- `src/config/site.js` — контакты и службы доставки.
- `src/data/works.js` — портфолио и лента.
- `src/payment/provider.js` — подготовка текста заказа без фиктивной платёжной системы.
- `public/photos/` — фотографии работ.
- `.github/workflows/build.yml` — сборка и публикация GitHub Pages.
- `docs/` — техническая и визуальная документация.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Деплой

Push в `main` запускает GitHub Actions. Vite использует `/AliPaySite/` на GitHub Pages и `/` при локальном/корневом размещении.

Workflow после сборки создаёт `dist/404.html` из production `index.html`, поэтому прямой переход на неизвестный путь GitHub Pages не должен отдавать пустой 404 вместо приложения.

## Контент

Фотографии должны быть реальными фотографиями работ. Иконка лисы используется только как маскот и fallback для брендинга; она не является фотографией изделия.

## Важные правила

- Описывать AliPay как сервис нанесения дизайна на готовые вещи.
- Не добавлять фиктивную онлайн-оплату без backend.
- Не рисовать самодельные логотипы служб доставки.
- Не ломать базовый путь GitHub Pages `/AliPaySite/`.
