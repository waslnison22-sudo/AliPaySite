# AliPay — custom clothing

Чистая витрина/магазин кастомной одежды.

- портфолио реальных работ;
- editorial-вёрстка без шаблонной сетки интернет-магазина;
- лис как основной маскот;
- заказ открывает интерфейс заказа;
- Platega пока не подключена: сайт безопасно переводит заказ в Telegram мастера;
- оформление заказа ведёт в Telegram мастера.

Platega подключается позже через backend. Секреты X-MerchantId и X-Secret не должны попадать во frontend. Текущая документация Platega использует POST /v2/transaction/process и callback для статусов.
