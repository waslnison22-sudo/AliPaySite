# AliPay — custom clothing

Чистая витрина кастомной одежды.

- портфолио реальных работ;
- editorial-вёрстка без шаблонной сетки интернет-магазина;
- лис как основной маскот;
- оформление заказа ведёт напрямую в Telegram мастера;
- онлайн-оплата пока не подключена, поэтому сайт не имитирует несуществующую платёжную систему.

Если онлайн-оплата будет добавлена позже, платёжные секреты должны храниться только на backend и никогда не попадать во frontend.
