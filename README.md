# AliPaySite 💳

Лендинг с **аккуратной заглушкой оплаты** и подготовленной архитектурой для реального эквайринга.

## Стек (лучший выбор для такой задачи)

- **React 18 + Vite** — быстрая современная сборка, стандарт для лендингов;
- **Чистый CSS** — без лишних зависимостей, легко кастомизировать;
- **Платёжная абстракция** (`src/payment/provider.js`) — интерфейс `PaymentProvider` с переключением реализации через `.env`.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```

## Что сейчас работает (заглушка)

- Страница с тарифами и кнопкой «Оплатить»;
- Клик имитирует платёж: задержка ~1 сек → сообщение **«Демо-платёж выполнен (без списания средств)»** и фиктивный ID `stub_...`;
- Явно видно, что это заглушка (бейдж «Режим: заглушка»).

## Как подключить настоящую оплату

1. **Выберите провайдера**
   - 🇷🇺 **ЮKassa** — лучший выбор для РФ/СНГ (карты, СБП, кошельки);
   - 🌍 **Stripe** — международные платежи (если доступен в вашем регионе).
2. **Добавьте бэкенд** (например, Node/Express): секретные ключи **нельзя** класть во фронтенд. Эндпоинт `POST /api/payments/create` создаёт счёт через API провайдера и возвращает `confirmation_url`.
3. **Сконфигурируйте окружение**: скопируйте `.env.example` → `.env`, заполните `VITE_PAYMENT_PROVIDER=yookassa|stripe` и ключи.
4. **Классы-заготовки** `YooKassaProvider` / `StripeProvider` в `src/payment/provider.js` уже вызывают нужные эндпоинты — останется лишь написать серверную часть.
5. **Webhook**: настройте на бэкенде приём уведомлений об оплате от провайдера.
