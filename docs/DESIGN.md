# Визуальная система AliPay

## Направление

Премиальная тёмная editorial-витрина для кастомизации готовых вещей.

Не использовать:

- белый интернет-магазин;
- SaaS/dashboard;
- cyberpunk/RGB;
- тяжёлые HUD;
- одинаковую сетку карточек;
- самодельные логотипы служб.

## Слои

1. Чёрный фон.
2. Мягкие градиентные свечения.
3. Glass surfaces с blur.
4. Фотографии как основной визуальный материал.
5. Тонкие линии и крупная типографика.
6. Тёплый оранжевый как редкий акцент.

## Motion

При прокрутке элементы появляются по мере входа в viewport. Дополнительно используется тонкая линия прогресса чтения сверху.

Motion не должен мешать чтению. При `prefers-reduced-motion: reduce` все декоративные анимации отключаются.

## Delivery

Блок доставки — тёмная трёхколоночная композиция. Логотипы СДЭК, Почты России и DPD подключаются как реальные брендовые изображения, а не как самодельные иконки.
