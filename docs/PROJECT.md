# AliPaySite — проектная документация

## 1. Назначение

AliPay — визуальная витрина кастомизации готовых вещей. Основная задача сайта — показать реальные работы, объяснить два варианта заказа и перевести клиента в Telegram.

Сайт не является полноценным интернет-магазином и не является ателье.

## 2. Модель заказа

### Вариант 01 — наша основа
AliPay предоставляет готовую футболку или шоппер и наносит согласованный рисунок.

### Вариант 02 — вещь клиента
Клиент передаёт подходящую готовую вещь. AliPay наносит на неё согласованный дизайн.

После согласования уточняются рисунок, расположение, сроки, стоимость, оплата и доставка.

## 3. Визуальная система

- База: почти чёрный `#080808`.
- Поверхности: полупрозрачные тёмные слои.
- Акцент: тёплый оранжевый.
- Стиль: editorial / fashion / custom print.
- Glassmorphism используется как слой, а не как набор одинаковых карточек.
- Белые полноэкранные секции запрещены.
- Движение мягкое: reveal, scale, blur и небольшой parallax без тяжёлого эффекта.
- Уважать `prefers-reduced-motion`.

## 4. Контентные правила

Запрещены формулировки, создающие впечатление собственного пошива или производства одежды.

Допустимая лексика: «готовая вещь», «основа», «нанесение», «рисунок», «дизайн», «вещь клиента», «наша футболка», «наш шоппер».

## 5. Изображения

`public/photos/` содержит только реальные изображения, используемые в портфолио. Лиса — отдельный SVG-маскот и не должна попадать в список работ.

Если фотография не загрузилась, интерфейс показывает нейтральный fallback `PHOTO UNAVAILABLE`, а не маскота.

## 6. Навигация

Страница использует якоря: `#works`, `#feed`, `#about`, `#delivery`, `#order`.

Прямые неизвестные URL на GitHub Pages обрабатываются через `dist/404.html`, который является копией production index.

## 7. Accessibility

- skip link;
- semantic buttons/links;
- focus-visible;
- focus trap в модальных окнах;
- восстановление фокуса;
- стрелки ←/→ в просмотрщике;
- reduced-motion режим.
